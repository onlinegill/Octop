02 / Overall direction

Easier, smarter, safer, and more token-efficient.

Octop's product evolution follows four clear directions: lowering the barrier to using an AI assistant, improving collaboration and reasoning quality on complex tasks, establishing verifiable safety boundaries, and running long-horizon tasks at a lower token cost.

↗
Easier

Lower the barrier and work out of the box, so users get an actionable AI assistant in the familiar Web, CLI, and IM environments.

✦
Smarter

Use multi-expert collaboration and context management to help agents understand longer task chains and handle more complex division of labor and reasoning.

◇
Safer

Through user/data isolation, permission control, and progressive sandboxing, keep AI within controllable boundaries while working in real environments.

↓
More token-efficient

Carry long-horizon context with filesystem offload, layered prompts, and layered memory to reduce wasted repeated reasoning and cost.

Product highlights shaped by these directions

Turning product ideas into deployable, collaborative, runnable capabilities.

01
Multi-user × multi-expert architecture

Each user can create multiple independent agents and pick roles from the expert library; MBTI personas and system prompts keep roles stable over time with clear division of labor, laying the foundation for lightweight multi-user collaboration and future AgentTeams.

02
Separated compute/storage with pluggable backends

Backend storage can live locally, in Docker, or on COS/S3; decoupling compute from storage makes deployment on enterprise infrastructure easier, and memory travels with the workspace.

03
Context management and token efficiency

Filesystem offload, layered prompts, layered memory, and full-text search keep long-lived information retrievable on demand, so the context window is not filled with useless content.

04
Connectors and real-environment operation

Connectors (OAuth + MCP), browser automation, an interactive Shell, remote desktop, and ACP connect AI to external systems, terminals, the web, and GUI workflows.

05
Proactive service and AI personas

Scheduled tasks can push proactively; MBTI personas and custom system prompts move agents from passive Q&A to a long-term partner with a consistent service style.

06
Continuously hardened safety boundaries

Today: JWT user isolation, tool approvals, Shell command guardrails, and sensitive-data redaction; next: research rootfs data isolation and full agent sandboxing.

04 / Roadmap

Teams / self-evolution / clients / plugin mechanism

The following covers short- and longer-term plans.

Near term / security foundation

Isolation moves from permissions to runtime

  • Research rootfs-based user data boundaries
  • Advance sandboxed agent execution and least privilege
  • Turn isolation, approvals, and auditing into verifiable security capabilities
Mid term / self-evolution and intelligent collaboration

From multiple agents to AgentTeams

  • Multi-agent formations, division of labor, and orchestration
  • Distill conversation experience into reusable skills
  • Strengthen context management and token efficiency
Expansion / product and platform

From validation to scaling up

  • Browser-recorded Octop validation
  • PC and mobile collaboration to broaden use cases
  • Feed mature capabilities back into upper-layer platforms such as lh and clawpro
